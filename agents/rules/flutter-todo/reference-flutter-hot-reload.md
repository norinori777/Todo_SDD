# Flutterのホットリロードを積極的に行うルール

このプロジェクトの `lib/` 配下にある `.dart` ファイルを編集・変更した場合は、次の手順に従ってください。

1. **実行を省略する場合:**
   - **`lib/`以外のファイル:** ホットリロードまたはホットリスタートを実行するのは、`lib/` 配下を編集した場合のみです。他のディレクトリ（例: `test/**`、`integration_test/**`、`benchmark/**`、`test_driver/**`、`example/**`）のファイル変更では実行しないでください。
   - **コメントとドキュメント:** 変更がコメント、ドキュメントコメント、空白文字だけの場合は、ホットリロードまたはホットリスタートを実行しないでください。

2. **実行中のアプリを検出して接続する:**
   - Dart MCPサーバーの `dtd` MCPツール（または `list_running_apps` / `vm_service`）を使って、実行中のアプリケーションのインスタンスを検出してください。

3. **ホットリロードまたはホットリスタートを実行する:**
   - UIウィジェット（Stateful Widgetの `build` メソッドを含む）または単純なメソッドを変更した場合は、変更後すぐに `hot_reload` MCPツールを実行してください。
   - 基本的なロジック、状態の初期化（例: `initState`）、グローバルまたはstaticな状態、あるいは `main()` を変更した場合は、`hot_restart` MCPツールを実行してください。
