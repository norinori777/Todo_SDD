# データモデル: Todo一覧画面

以下は論理モデルであり、Markdown以外の永続データベースを意味しない。

## ノート

| 項目 | 内容 / 検証 |
|---|---|
| 識別子 | 設定フォルダー内の対象を一意に開くための識別子。相対パスは表示・並び替えにも使用し、フォルダー外を指すものを拒否する。 |
| タイトル | 拡張子を除くファイル名。同名でも別ノートとして保持する。 |
| タグ | 本文とfrontmatterの対象タグ。先頭の`#`を正規化し階層は保持する。コード・コメント・HTMLのタグと属性・エスケープ・URLおよびWikiリンクと通常のMarkdownリンクのリンク先は対象外、HTML要素内および各リンクの表示文字は対象。階層タグは`#仕事/会議`のように全体を表示する。 |
| Wikiリンク | 本文およびfrontmatterの対象リンク。ノート名、ルート起点パス、見出し、表示名を分離して扱う。コード・HTMLコメント内は除外する。 |
| 元データ / 読込時の版 | 変更判定と部分編集のための元テキストと比較可能な内容。表示や外部送信には使用しない。 |

対象はUTF-8であり、UTF-8 BOMは許容して保持する。別形式のBOMや不正なUTF-8、frontmatterが不正、`tags`が非対応型またはリスト内に文字列以外を含む場合はノートを対象から除外し、識別情報と理由を読込結果に残す。`tags`は文字列、文字列のみのインライン・複数行リスト、空リストを受け付ける。

本文でタグ開始の`#`の直前が文字・結合文字・数字・`_`・`-`・`/`の場合はタグとせず、行頭またはそれ以外の文字の直後はタグとする。タグ名にも同じ文字を含める。既定の除外領域は対象外とする。書式を正しく判定できずTodoのタグを特定できない場合もノートを除外し、識別情報と理由を読込結果に残す。

## Todo

ノートのタグに完全一致の`todo`がある場合に成立する。`todo/子`だけでは成立しない。タグに完全一致の`完了`がある場合は完了、それ以外は未完了。タイトル、識別子、タグ、関連情報は元ノートから得る。

| 操作 | 前 | 永続化後 | 変更範囲 |
|---|---|---|---|
| 完了 | 未完了 | 完了 | frontmatter直後、またはfrontmatterがないとき先頭に独立した`#完了`行を追加。 |
| 未完了に戻す | 完了 | 未完了 | 判定対象の本文とfrontmatterの完了タグをすべて削除。`tags`が空なら`tags: []`。Wikiリンク表示名が`#完了`のみの場合は表示名部分を除去しリンク先を保持。通常のMarkdownリンク表示文字が`#完了`のみの場合はリンク先を表示文字に使い、表示文字中の`#`をエスケープしてリンク先を保持する。 |

保存前の内容が読込時と異なる場合は遷移しない。保存失敗または安全な保存が保証できない場合も成功扱いせず、元データを守り、理由と対処を通知する。
保存中のアプリ強制終了・端末再起動からの復旧、およびその後に外部変更があった場合の両内容の保持と利用者による選択は[仕様](./spec.md)のFR-009、FR-015に従う。

## 保存操作と復旧

| 状態 | 保持・遷移条件 |
|---|---|
| 読込済み | 対象の安定した識別子、読込時の完全なバイト列と版を保持する。保存能力が不明なら閲覧専用。 |
| 準備済み | 選択フォルダー内の識別可能な復旧領域に、対象、更新前・更新後の完全なバイト列と操作状態を耐久化する。準備できなければ対象を変更しない。 |
| コミット中 | 保存直前の版を条件に更新する。比較と確定の間の競合を防ぐ保証がない提供元では開始しない。 |
| 確定 | 更新後の完全な内容と耐久性を確認後にのみ成功を返す。復旧情報の安全な片付けにも途中失敗時の再開方法を設ける。 |
| 復旧待ち | 中断後に対象と復旧情報を読む。元または更新後の完全な内容に安全に戻せる場合を除き、自動上書きしない。判定不能や外部変更は競合として扱う。 |
| 競合 | 現在と復旧用の内容を保持して各全文を表示する。正しい文字列でなければ全バイトの16進数を表示する。どちらか読めなければ理由・対処を通知して選択を無効化する。 |
| 選択後 | 現在を残す、または復旧用を適用する。いずれも確認後の外部変更を再検査し、競合時は保持して再確認する。安全な確定ができるまで復旧情報を残す。 |

復旧領域の名前や方式は既存ファイルを上書きしないものに限る。対象の版判定・耐久化・条件付き確定・再起動後の復旧が提供元で保証できない場合は、その提供元での更新を拒否する。能力の検証は実装・公開ゲートであり、このモデルだけで実現を保証しない。

## 関連情報

Todoと他のノート間の直接Wikiリンクを方向に関係なく1件として表す。リンク先が見出し・表示名付きでもノート自体を参照する。パス付きリンクは指定フォルダー起点。未解決・読込不能・複数候補は解決済みのノートと区別して表示・通知し、任意の候補を開かない。同名の関連項目には相対パスを表示する。

## 一覧状態

- **検索条件**: 空、タイトル部分一致、`#`から始まるタグ完全一致。タイトルの英字は大文字・小文字を区別せず、タグは区別する。タグ検索はNFCに正規化して比較し、元ファイルは変更しない。`#完了`のみ完了Todoを対象とする。
- **読込状態**: 読込中、成功（空結果を含む）、部分成功（読めた項目と対象別の失敗）、全体失敗。全体失敗を空結果に変換しない。
- **表示項目**: タイトルはUnicodeコードポイントの辞書順で昇順、同名は相対パスも同じ辞書順で昇順。重複タイトルには相対パスを表示する。
- **展開状態**: Todoごとの関連情報の開閉。初期値は閉じる。
- **画面復帰**: 作成・編集・詳細から戻るたびに再読込し、検索条件を維持する。再読込失敗も通知する。
