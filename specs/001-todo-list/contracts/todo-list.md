# Todo一覧の利用者・機能間契約

## 一覧操作

| 入力 / 操作 | 結果 |
|---|---|
| 一覧を開く | 指定フォルダーと全サブフォルダーを読み、未完了Todoをタイトル昇順、同名は相対パス昇順で表示。読込中、空結果、失敗、部分失敗を区別する。 |
| タイトル文字列を入力 | 未完了Todoのタイトルに対する、英字の大文字・小文字を区別しない部分一致。 |
| `#`に続くタグを入力 | 未完了Todoの本文・frontmatterのタグをNFCで正規化して完全一致。元ファイルの表記は保持する。`#完了`は完了Todoのみ。入力を消すと通常一覧に戻る。 |
| Todoをタップ / 長押し | 同じノートの詳細 / 編集を開く。作成ボタンは作成画面を開く。 |
| 左スワイプ / 操作メニューの状態変更 | 対象を完了・未完了に切り替える。永続化が失敗または拒否された場合、成功表示せず対象と対処を伝える。操作メニューは読み上げ可能で、編集も選択可能。 |
| 関連情報を展開 / 折りたたむ | 初期状態は閉じる。直接リンクされたノートを双方向に表示し、同じノートは1件とする。 |
| 関連タイトルをタップ | 解決済みの対象ノートの詳細を開く。未解決、複数候補、読込不能なら誤った対象を開かず状況と対処を表示する。 |
| 作成・編集・詳細から戻る | 同じ検索条件で再読込し、失敗を通知する。 |

同名のTodoまたは関連情報には指定フォルダーからの相対パスを併記する。タグ、Wikiリンク、保存の詳細は[データモデル](../data-model.md)と[仕様](../spec.md)を参照。
階層タグは`#仕事/会議`のようにタグ全体を表示する。タイトルの並び順はUnicodeコードポイントの辞書順とし、検索時の英字の大文字・小文字の扱いとは区別する。

## 機能間の境界

- **設定 → 一覧**: 設定機能は利用者が指定したフォルダーへのアクセス情報と権限エラーを公開する。未設定・失効・権限不足を正常な空フォルダーとして扱わない。
- **一覧 → 詳細・編集**: 選択したノートの識別子を渡す。作成には既存ノート識別子を渡さない。遷移先の内部仕様は対象外。
- **Repository → 一覧**: 正常に読めたノート、対象ごとの失敗、全体失敗を区別する型付き結果を返す。状態更新は成功、外部変更、権限・読み書き失敗、安全な保存を保証できない場合を区別する。
- **保存保証**: 実ファイルとAndroidの対象提供元で検証できない書き込み方式は拒否し、元ファイルを破壊しない。事前比較だけでその後の競合を防げるとはみなさない。
- **中断からの復旧**: 保存中のアプリ強制終了・端末再起動後に更新前または更新後の完全な内容を復元可能とする。外部変更と競合した場合は両内容を保持して確認・選択できるようにし、読取不能時や表示形式の扱いは[仕様](../spec.md)のFR-015に従う。
- **復旧時の利用者操作**: 現在の内容と復旧用の内容をそれぞれ全文表示する。不正なUTF-8は読めない旨と全バイトの16進数を表示する。どちらかを読み取れない場合は対象・理由・対処を示し、選択と上書きを無効にする。確認後の外部変更も再検査し、変更されていれば選択を実行せず再確認する。
- **保存能力境界**: 呼び出し側は、読込時の対象・版、完全な更新後の内容を渡し、成功・外部変更・権限/読書失敗・安全性未確認・復旧待ちを区別する。実装は指定フォルダー内で復旧情報を耐久化し、比較と確定の間の競合を防ぐ条件付き確定を保証できない場合は更新を拒否する。詳細な状態は[データモデル](../data-model.md)に従う。

外部ネットワークAPIは提供せず、Markdownやファイル情報を送信しない。
