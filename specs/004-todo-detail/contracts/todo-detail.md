# Todo詳細画面の利用者契約

## 一覧からの遷移

| 操作 | 結果 |
|---|---|
| Todoをタップ | 選択したTodoの識別子と内容を詳細画面へ渡す。他のTodoの情報を混在させない。 |
| 詳細を閉じる / 戻る | 直前の一覧へ戻る。一覧の検索条件を維持し、一覧データを再読込する。 |
| 詳細画面でタグをタップ | Todo一覧へ移動し、そのタグに完全一致するTodoだけを表示する。既存のタグ検索規則を使う。 |

## 表示と操作

- Todoタイトル、本文のMarkdownプレビュー、タグを参照専用で表示する。
- 階層タグは階層全体が分かるように表示する。
- Todo本文に直接Wikiリンクがある場合、関連情報の見出しの下に解決済み文書のタイトルを表示する。同じ文書は重複表示しない。
- 関連タイトルをタップすると対応するMarkdownの参照専用プレビューを開く。戻るとTodo詳細へ戻る。
- 本文、タグ、関連リンクのいずれかがない場合、その欠落を空の項目で補わず、残りを表示する。
- 詳細画面に編集、削除、関連情報作成の操作を表示しない。外部URLや未対応リンク先を起動しない。

## 読み込み失敗

- Todoを読み込めない場合は、失敗と必要な対処を表示し、空のTodoを正常な詳細として表示しない。
- 関連Markdownが見つからない、曖昧、または読み込めない場合、候補を勝手に選ばず、対象を開けなかったことを通知する。
- 失敗時も詳細画面から戻る操作を利用できる。

## 機能間境界

- Todo一覧は選択Todoを渡し、詳細画面は読み取り専用の表示と関連参照を担う。
- Markdown探索・解析・リンク解決はTodoデータ境界を通す。Widgetはパス操作、ファイル読み込み、Markdown解析を行わない。
- 永続データはアプリで設定されたMarkdownフォルダーにあり、詳細機能から書き込まない。
- HTTP APIや外部サービスとの契約は提供しない。
