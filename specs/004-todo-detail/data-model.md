# データモデル: Todo詳細画面

これは表示用の論理モデルであり、新しい永続ストレージやMarkdown書き換えを導入しない。

## 選択されたTodo

一覧で選択された既存の`Todo`を遷移時の識別情報とし、詳細Repositoryが指定フォルダーから再読込して詳細スナップショットを構成する。

| 項目 | 内容 / 検証 |
|---|---|
| 識別子 | `NoteId.relativePath`。指定フォルダー相対で、フォルダー外を指す識別子は既存の`NoteId`検証で拒否する。 |
| タイトル | `Note.title`。選択したMarkdownファイル名から得る。 |
| 本文 | `Note.content`のMarkdown文字列。表示専用であり、画面から変更・保存しない。 |
| タグ | `Todo.tags`。既存のタグ値を保持し、階層タグは階層全体を判別可能に表示する。タップ時はそのタグでTodoを絞り込む。 |

詳細画面は選択された識別子と再読込したTodoの内容を同一の詳細表示に用い、別Todoのデータを混在させない。選択した識別子のTodoが見つからない、または読み込めない場合は成功状態や空のTodoへ置き換えず、失敗として表示する。

## 関連Markdown参照

関連情報は選択Todoの本文にある直接Wikiリンクから導出する。Todoとは別のMarkdown文書であり、永続化された関連エンティティではない。

| 項目 | 内容 / 検証 |
|---|---|
| リンク元 | 選択TodoのMarkdown本文。タグ、他ノートの逆リンク、リンク先から連鎖するリンクは対象にしない。 |
| リンク記法 | Todo一覧機能のWikiリンク解析・解決契約と同じ対象構文を利用する。 |
| 解決範囲 | アプリで設定したフォルダー内。パス指定はフォルダー相対として検証し、フォルダー外への参照は解決しない。 |
| 表示タイトル | 解決した`Note`のタイトル。同じ対象`NoteId`への複数リンクは一件にまとめる。重複タイトルは相対パスで区別する。 |
| タップ | 解決済み対象のMarkdownプレビューを開く。外部URLや不明な宛先を起動しない。 |
| 未解決・複数候補 | 対象を推測せず、開けなかったことを表示する。別候補を誤って開かない。 |
| 読込失敗 | 参照先が見つからない、または読み込めないときは失敗と対処を示し、正常な文書として表示しない。 |

リンク解決の候補規則は[Todo一覧のデータモデル](../001-todo-list/data-model.md)と[契約](../001-todo-list/contracts/todo-list.md)を共通規則とする。詳細画面の関連一覧はこの機能仕様に従い、選択Todoからの直接リンクに限定する。

## 表示状態と遷移

| 状態 | 内容・遷移 |
|---|---|
| 読込中 | 選択Todoと関連Markdownの必要な情報を取得中。 |
| 表示可能 | タイトル、取得可能な本文とタグ、解決済みの関連タイトルを表示。存在しない情報は表示しない。 |
| 関連なし | 関連リンクがない場合、関連情報の項目を表示しない。本文・タグは通常どおり確認できる。 |
| Todo読込失敗 | 読み込み失敗を通知し、空のTodoを詳細として表示しない。 |
| 関連先読込失敗 | 誤った文書を開かず、対象を開けないことと対処を通知する。 |
| 戻る | 詳細を閉じ、直前のTodo一覧へ戻る。検索条件を維持し、一覧を再読込する。 |
| タグ選択 | Todo一覧へ移動し、選択されたタグが付くTodoだけを表示する。 |

詳細画面ではMarkdownの編集、Todoの更新・削除、関連情報の作成を行わない。Markdown本文・ファイル・タグを変更する状態遷移はない。
