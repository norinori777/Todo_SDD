# Todoアプリ要件

## 目的

- Obsidianでマークダウンで色々なことを管理しているが、Obsidianは、汎用てきなアプリのため、Todoだけ参照したい場合、他のmarkdownも含まれており見ずらい。
- そのため、todoに特化したマークダウン管理（参照、作成、更新、削除）のツールを作成する。

## 機能概要

### 一覧画面（TOP画面）

- Obsidianのタグ方式でtodoタグが付いたものをリスト表示できるようにする。
  - リスト項目の表示内容
    - タイトル
- 階層タグになっているものは、階層が分かるように表示すること。
- リスト表示からTodoの進捗を更新できるようにする。Todoのリスト項目を左にスワイプしたらTodo完了とする。
- Todoリストの項目をタップすると詳細画面に遷移すること。
- TodoタグからLinkされたマークダウンについても関連情報のタイトルを表示すること。
  - 関連情報は、普段隠れているが、何かのアクションで関連情報のタイトルがリスト表示されるようにすること。
  - 表示された関連情報をタップすると詳細画面に遷移すること。
- Todoリストは、以下の検索ができること。
  - タイトルから検索可能なこと。
  - #文字列で入力するとタグの絞り込みが可能なこと。
  - #完了で完了タスクが検索できること。
- 参照画面からタスク作成ボタンをクリックすると作成画面に遷移すること。

### 作成画面

- 一覧画面から作成ボタンをクリックして作成画面に遷移すること。
- Todoを作成できること。
  - 入力項目は以下とすること。
    - タイトル
      - 必須
    - 内容（マークダウン形式で入力できること）
      - #を入力したら、すべての登録済みのタグが候補して表示されること。入力していくと部分マッチしているものにて候補が絞られる動作をすること。候補がない場合にEnterを押した場合は、新規タグとして追加されること。
        - 任意
        - TODOのタグ
          - 自動で付与

            ```Text
            // 以下の形式
            # TODO
            ```

      - 既存のTodoから関連情報を入力できること
        - タイトル
          - 必須
        - 内容（マークダウンで入力できること）
          - 任意
        - 関連対象の既存マークダウンファイルへのリンクを付与
          - [[を入力したら、すべてのマークダウンが候補して表示されること。入力していくと部分マッチしているものにて候補が絞られる動作をすること。候補がない場合にEnterを押した場合は、何も追加されないこと。
          - 自動で付与

            ```Text
            // 以下の形式
            [[<既存のマークダウンタイトル>]]
            ```

  - 入力モードと参照モードが切り替えられること。
    - 参照モードの場合、マークダウンの参照形式で表示されること。また、入力できず、参照のみとなること。
    - 入力モードの場合、マークダウンの入力形式で表示されること。また、入力できること。

## 詳細画面

- 参照画面のTodoのリスト項目をクリックして詳細画面に遷移すること。
- １つのTODOをマークダウンのプレビューモードで表示します。
-　表示する内容は、以下とする
  - タイトル
  - 内容
    - 関連情報([[マークダウンタイトル]])は、リンクとして、表示すること。リンクをクリックした場合、対象のマークダウンが表示されること。
    - タグのリンクをクリックした場合、
- 遷移した場合、戻るボタンで戻れること。

## 編集画面

- 参照画面のTodoのリスト項目を長押しして、編集画面に遷移すること。
- Todoを編集できること。
  - 入力項目は、以下とすること。
    - タイトル
    - 内容（マークダウンで入力できること）

### 設定

- マークダウンを参照、格納するフォルダーを設定画面から指定できること。
